Code signing policy

Kod imzalama politikası

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Windows releases of Evrakçı (Evrakci-win-Setup.exe and the program files Evrakci.exe, Evrakci.dll, Evrakci.Core.dll) are built from the public source code at github.com/cahitarslan/evrakci by GitHub Actions and signed through SignPath. Only binaries built from this repository are signed. Third-party components (the .NET runtime, WPF-UI, Velopack) are shipped as published by their maintainers.

Team roles

  • Committers and reviewers: Cahit Arslan
  • Approvers: Cahit Arslan

Every release is approved manually before it is signed. Contributions from other people are reviewed before they are merged.

Privacy policy

Evrakçı works offline. Documents, case files and everything typed into the program stay on the user's computer and are never sent anywhere.

The only network access is an optional update check. On first start the program asks whether it may check for updates. If the user agrees, it requests https://evrakci.netlify.app/guncelleme/releases.win.json on each start and downloads a newer version from the same address if one exists. The request carries only the installed version number and the Windows architecture (for example 1.1.0, x64) so the right package can be offered; it contains no personal data, documents or user identifiers. The server also sees what any web request reveals, such as the IP address. The check can be turned off at any time in the theme menu (top right): “Güncellemeleri otomatik denetle”. Apart from this, the program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The website evrakci.netlify.app uses no cookies or visitor tracking. It is hosted by Netlify (Netlify privacy policy); the contact form is processed by Netlify Forms and used only to reply.

Gizlilik

Evrakçı internetsiz çalışır. Belgeler, dosyalar ve programa yazılan her şey bilgisayarda kalır; hiçbir yere gönderilmez.

Programın tek ağ bağlantısı isteğe bağlı güncelleme denetimidir. İlk açılışta güncellemelerin denetlenip denetlenmeyeceği sorulur. Onay verilirse her açılışta https://evrakci.netlify.app/guncelleme/releases.win.json adresine bakılır, yeni sürüm varsa aynı adresten indirilir. İstekte yalnızca kurulu sürüm numarası ve Windows mimarisi (ör. 1.1.0, x64) bulunur ki doğru paket sunulabilsin; kişisel veri, belge ya da kullanıcı kimliği yoktur. Sunucu ayrıca her web isteğinde görünen bilgileri, örneğin IP adresini görür. Denetim, sağ üstteki tema menüsünden (“Güncellemeleri otomatik denetle”) istenildiği zaman kapatılabilir. Bunun dışında program, kullanıcı ya da programı kuran veya kullanan kişi özellikle istemedikçe başka bir sisteme bilgi göndermez.

evrakci.netlify.app çerez ya da ziyaretçi takibi kullanmaz. Site Netlify'da barınır (Netlify gizlilik politikası); iletişim formu Netlify Forms ile işlenir ve yalnızca yanıt vermek için kullanılır.
